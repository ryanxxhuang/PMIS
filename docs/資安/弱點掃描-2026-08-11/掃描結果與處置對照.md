## 逐項處置

### A. 隨 hosting 移轉解決（7 類,同一根因）

| ZAP 規則 | 內容 | 移轉後的作法 |
|---|---|---|
| 10038 CSP Header Not Set | 未設 Content-Security-Policy | 設 CSP 標頭(`default-src 'self'` 基礎,允許 Supabase API) |
| 10020 Missing Anti-clickjacking | 未設 X-Frame-Options／frame-ancestors | `X-Frame-Options: DENY` ＋ CSP `frame-ancestors 'none'` |
| 10021 X-Content-Type-Options | 未設 nosniff | `X-Content-Type-Options: nosniff` |
| 10063 Permissions Policy | 未設 Permissions-Policy | 停用不需要的瀏覽器能力(camera 除外——照片上傳要用) |
| 90004 COEP Missing | 未設 Cross-Origin-Embedder-Policy | 設 COOP／COEP(需先驗證與照片上傳、PDF 檢視相容) |
| 10098 Cross-Domain Misconfiguration | GitHub Pages 全站回 `Access-Control-Allow-Origin: *` | 移轉後移除萬用 CORS;純靜態資產,實際風險低 |
| 10015／10049／10050 Cache 相關 | 靜態資產可被快取 | 移轉後對 `index.html` 設 `no-cache`,hashed assets 維持長快取(本來就該快取) |

> 💡 **為什麼不現在用 `<meta>` 標籤補 CSP**:meta 版 CSP 不支援 `frame-ancestors`、
> 不能涵蓋 X-Frame-Options 與 HSTS,只能解決 13 項中的 1 項的一部分,
> 且移轉後要改寫成標頭版——重工。**決策:全部集中在 hosting 移轉時一次做對。**(2026-08-11)

### B. 不適用／誤報（4 類,附理由）

| ZAP 規則 | 內容 | 處置理由 |
|---|---|---|
| 10096 Timestamp Disclosure | JS bundle 內出現類 Unix timestamp 數字 | **誤報**:命中的是 demo 資料檔(`workItems.compact`)中的工程數量常數,非系統時間戳,無資訊洩漏 |
| 10055 CSP Directive No Fallback | 404 頁的 meta CSP 缺 fallback | 命中的是 **GitHub 自己的 404 頁**(`robots.txt`/`sitemap.xml` 不存在時 GitHub 回的頁),非本服務頁面;隨 hosting 移轉自然消失 |
| 10109 Modern Web Application | 「這是現代 SPA」 | **資訊性提示**,非弱點 |
| 90003 SRI Missing | script 標籤未帶 integrity | 本服務**所有 script 均為同源自載**(無第三方 CDN),SRI 防護的「第三方資源被竄改」情境不存在;Vite 產出之 hashed filename 已提供內容定址 |

### C. 已由其他機制涵蓋（掃描範圍外,主動說明)

| 項目 | 說明 |
|---|---|
| HSTS | `*.github.io` 為瀏覽器 **HSTS preload** 網域,強制 HTTPS 已生效(掃描未報此項即為證);移轉自有網域後需自行設定 HSTS 標頭並確認 |
| 後端 API | 資料層為 Supabase 託管(PostgREST + RLS),伺服器端授權以 pgTAP 635 項自動化測試釘住;對第三方託管基礎設施進行主動掃描涉其服務條款,不在本次範圍 |
| 認證層 | 帳號鎖定、密碼政策等「識別與鑑別」構面項目另依 `資通系統防護基準-普通級-符合性對照.md` 補強清單辦理 |
