## 視覺來源：`UIUX/design_handoff_pmis_google_ui/README.md` ＋ `src/index.css`

這份簡報不是「配色抄產品」，是直接套產品的 design token：

| 項目 | 值 | 出處 |
|---|---|---|
| 字型 | 一套 `Noto Sans TC` 中英共用 | index.css 的 harmonized family |
| 字級 | handoff 的 px 值直接當 pt：標題 24、卡片標題 15、正文 13、輔助 11.5、大數字 28 | 1440px 畫面 → 13.33in 版面再放大 1.5 倍，剛好 1px = 1pt |
| **字重** | **頁面標題與大數字一律 400，不是粗體** | handoff 字級表。這是「像不像 Google」最關鍵的一項 |
| 字距 | 不放大 | handoff：「不使用小型大寫或字距放大」 |
| 顏色 | 底 `#f8fafd`／卡面 `#fff`／卡線 `#e3e6ea`／文字 `#202124` `#5f6368` `#6a6e73` | index.css |
| 狀態 | 五語意色票 danger／warn／ok／info／mute，顏色與文字並存 | handoff 第三版 |
| 圓角 | 卡片 12、chip 8、色票 6、登入卡 28 | handoff 圓角表 |
| 陰影 | shadow-sm `0 1px 2px rgba(60,64,67,.3)` | 同上 |

**兩條照抄的紀律**（改版時不要破壞）：

1. **卡片不鋪色底、不加彩色頂條。** handoff 明訂顏色只出現在色票與動作鈕上——
   第一版簡報每張卡上面壓一條彩色，那是簡報常見手法，但不是這個產品的樣子。
2. **品牌四色只出現在標誌與封面圖例，不進入任何元件。**
   介面的紅／黃已經有狀態語意（逾期／待確認），標誌的紅黃跑進卡片會誤導。

### 封面就是產品的登入頁

`#f8fafd` 底 ＋ 置中 28pt 圓角白卡 ＋ shadow-sm ＋ 標題 400 字重——
版面骨架直接取自 handoff 的 `/login` 規格。右邊放大的標誌是三方圖例：
三個點＝機關（藍）監造（紅）廠商（黃），灰三角＝同一份契約事實。
這張圖本身就在講產品在做什麼，比任何一句 slogan 有效。

### 為什麼標誌走 PNG 不走線段

三角形的底邊是水平線（高度 0），PowerPoint 與 LibreOffice 對零高度線段處理不一致，
會整條不見。`brand_mark.py` 依 `assets/brand/pmis-mark.svg` 的 48 單位座標算成去背 PNG，
超取樣 8 倍後縮圖，邊緣乾淨且幾何不會走鐘。

### 字型那步用 `fix_ea_fallback.py`，不要用舊的 `fix_ea.py`

舊檔是為「pptxgenjs 只寫 `<a:latin>`」的年代寫的；現在的 pptxgenjs（4.x）**會**寫 `<a:ea>`，
舊檔看到 ea 已存在就跳過。新檔三種情況都處理：換掉既有 ea／cs、補空的 `<a:ea/>`、
以及舊版只有 latin 的情況，並一併修佈景主題的 `minorFont/ea`。
合作簡報下次重建也該換成它。

⚠️ **`Noto Sans TC` 要裝在放映的那台電腦上**，否則 PowerPoint 會替換字型。
沒把握就用同目錄的 `.pdf` 放映，字型已經嵌進去了。

每頁 speaker notes 都有秒數配額，總長約 6 分 30 秒（規定 6 分鐘 ＋ 統問統答 3 分鐘）。

**P15 最後兩句不能砍。**

## 兩條講話紅線

1. **標的一律「雲端訂閱服務（SaaS）」**，不得出現「開發／客製／建置」——
   否則工程會一覽表的歸類會從「SaaS 套裝型」掉到「應用軟體或系統開發服務」，普級要求暴增。
2. **時程不寫死。金額只出現在 P09、P11、P12**，改一頁要三頁一起改。
   （這點與合作簡報不同：那份規定金額只出現在最後一頁，但附件4 第六、八項強制要求
   收入模式與三年財務預測。）
