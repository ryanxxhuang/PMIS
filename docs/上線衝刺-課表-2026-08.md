# Day 10（五 8/21）網域 ＋ 換 Hosting ＋ 安全標頭

喚醒詞：`跑課表 Day 10`

> ⚠️ **這三件事是綁在一起的技術必然，不是三件獨立的事**：
> **GitHub Pages 不支援自訂 HTTP header**，所以 CSP / HSTS / X-Frame-Options 在現在的 hosting 上
> 根本設不了（只能用 `<meta>` 的打折版）。
> 推導鏈：Day 8 的**弱點掃描是普通級明文要求** → 掃出來一定會報缺安全標頭 → 得修 →
> 現在的 hosting 設不了 header → 換 Cloudflare Pages → 順便換網域。
> （**注意**：「系統與通訊保護」構面在普通級是「無要求」，所以安全標頭本身不是條文要求，
> 是**弱點掃描結果**要求的。這個區別在跟機關解釋時講清楚會顯得你很懂。）

- **網域決策與購買** 💰 — 候選 `conpm.ai` / `sitesquad.ai` / `constructagent.ai`（.ai 約 US$70–100/年）
  ⚠️ **要你拍板產品名稱**，這件事拖太久了，Day 10 一定要決定
- **搬 hosting**：`ryanxxhuang.github.io/PMIS` 子路徑 → Cloudflare Pages ＋ 自有網域
  （順帶解掉「賣 15 萬的系統掛在個人 GitHub Pages 上」的信任問題）
- **安全標頭**：CSP、HSTS、X-Frame-Options、X-Content-Type-Options、Referrer-Policy
- 最終檢查：`npm test`、`npm run test:e2e`、pgTAP 全綠 → deploy
