## 結論

現況已把表單做成可編輯的紙本外觀，但操作仍以「上傳批次、候選文書、待補、建議、版本」為中心。使用者要的核心是：**打開表單 → 上傳照片 → AI 直接填入 → 工程師直接改 → 存檔。** 這需要改操作流程與填表能力，單純再藏幾個選單或加強照片 caption 不足以達成。

本輪只優先處理施工廠商桌面網頁：①施工文件（施工日誌、自主檢查表）；②契約與提醒；③估驗請款。Agent 聊天、Copilot、泛用分析及其獨立入口退出廠商工作介面。三方授權、監造確認量、歷史與簽署紀錄仍是這三項功能的必要支援。

## 目標畫面與操作

廠商左側只保留三個主入口：**施工文件／契約與提醒／估驗請款**。專案切換、帳號、必要設定放頁首或設定選單，不再另設今日工作、Agent、品質、工安、月報等平行工作區。今日到期事項嵌在契約提醒及相關表單中。

施工文件預設直接打開今日施工日誌，頂部只放：`施工日誌｜自主檢查表`、日期／文件選擇、`上傳照片，AI 填表`。下方就是可編輯的真實表單；照片拖到表單也能上傳。處理中顯示簡單進度，完成後原地填入，不要求進批次清單或接受候選文書。

底部固定「存檔」，正式交件時才顯示「審閱並簽署送出」，PDF 為次動作。存檔允許尚未補完，不等於簽署、提送或監造認可。簽署前一次檢視本版的關鍵數字、剩餘必填及確認聲明，不逐格點二十次確認。

表內值能直接改；AI 標記用淡底色或小點，點欄位才看來源。錯誤、缺資料只在該格與頂部「還有 N 項需補」顯示，不另做一套收件匣。刪列放到該列選取／滑入時出現，且保留鍵盤操作。

## AI 應填哪些內容

| 資料類型 | 預期自動化 |
|---|---|
| 工程名稱、承攬廠商、開工日、核定工期、契約量、單位 | 從專案／契約／標單帶入；欠缺的共用資料在表內一次補好，依授權存回正確來源 |
| 施工項目、施工概況、材料名稱、可見機具／工種、檢查描述 | AI 結合照片與工程背景擬寫可直接編輯的內容，不再只拼接照片 caption |
| 人員／機具數量 | 有當日紀錄就帶入；照片可見數量只能作「照片可見、待核對」建議；不能把單張照片人數當全天出工，多張同人同機不可重複加總 |
| 昨日沿用 | 沿用班組、材料與機具種類及適用敘述；昨日數量不自動變成今日實際值，若作建議須保留日期與來源 |
| 當日完成量、材料用量、實測尺寸 | 有可讀紀錄就直接填，不強迫重新鍵入；區分單位、方向、編號與位置；沒有數量依據就只差這個數字待人補 |
| 安全、教育、保險、技術士、抽驗、通知 | 有當日紀錄則填；照片支持的觀察可擬寫，其餘集中用少量選擇補完，不能把「未拍到」填成「無」或「全部合格」 |
| 天氣、工期、累計量、金額、進度 | 天氣依當日有效來源；其他由既有確定性規則計算。原始資料補齊後自動更新 |

「幾乎填完」應以減少工程師輸入為目標：可合理擬寫的文字積極填，能取得的既有資料全部帶，紙上已寫的值完整抄。必須誠實保留沒有來源的事實缺口，而不是整節空白，或用亂填的數量衝高完成率。

同一批照片可共用於日誌與自檢，但在目前表單先完成當前工作；另一份表以簡單切換存取，不自動冒出監造文件。AI 不覆寫工程師已改的欄位；有衝突才局部顯示比較。

## 契約與估驗的收斂

- 契約與提醒：同頁上傳契約、看到整理結果與「何時／誰／做什麼／依哪一頁條文」，就地補必要日期。掃描檔讀不到就明示處理狀態，不假裝已完成。提醒不依賴聊天 Agent。
- 估驗請款：監造已確認、尚未計價的數量自動帶入草稿；每列清楚顯示本期可請量、已請量、待確認原因與查驗來源。廠商在這裡能提出／追蹤查驗，無須回到獨立品質模組找入口。
- 沒有可估驗量時提供當下可做的事，例如「送監造查驗」，不堆滿稽核代碼。非實體項的計價依據不足仍明示原因，不因精簡解除後端限制。
- 必要的送審、補正、查驗、退回、變更與歷史，放在對應核心流程的詳情中。移除不必要的新作業入口及孤立程式；正式資料、有效權限與紀錄不可一併刪除。

## 交付順序與驗收

1. 先完成兩種表單的頁內上傳／編輯／存檔，以及移除廠商 Agent 等入口。
2. 再補逐節填表、雙向尺寸、多編號、多照片合併；共用資訊只補一次。
3. 接好契約提醒、查驗至估驗的必要操作；最後清除不再使用的 UI 與相依程式。

驗收必須用真實瀏覽器上傳這五張照片，走到存檔重載、人工修改、簽署提送、PDF 與監造確認後估驗。不只驗單一辨識函式或 stub。舊照片全已存在、邊編輯邊上傳、部分失敗、切換文件、辨識重跑均不得丟人工修改或產生重複文件。

建議交付門檻：有效照片／契約／既有資料能支持的欄位自動填入率至少 90%；另列整份表單非空率、正確率、人工修改數及操作時間，列出分母與仍需人工欄位，不以排除困難欄位宣稱全自動。你的三張紙表中的 8 筆雙向實測項目，要逐筆查驗「辨識→對應表格→保存→重載→PDF」，不能只報模型讀對 8 筆。
